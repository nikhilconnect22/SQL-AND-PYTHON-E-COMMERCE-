# SQL + Python E-commerce Data Analysis

This project analyzes an e-commerce dataset by combining **SQL** (via MySQL) for data querying with **Python** (pandas, matplotlib, seaborn) for data manipulation and visualization. It answers a series of real-world business questions about customers, orders, sales, and revenue.

## Tech Stack

- **Python 3**
- **pandas** – data wrangling and analysis
- **matplotlib** / **seaborn** – data visualization
- **mysql-connector-python** – connecting to and querying a MySQL database
- **MySQL** – relational database storing the e-commerce data (customers, orders, order items, payments, products, sellers)

## How It Works

1. A connection is established to a local MySQL database named `ecommerce` using `mysql.connector`.
2. SQL queries are executed against the database to extract relevant data (joins across `customers`, `orders`, `order_items`, `payments`, `products`, and `sellers` tables).
3. Query results are loaded into pandas DataFrames for further analysis.
4. Key metrics are visualized using matplotlib/seaborn (bar charts, etc.).

## Business Questions Answered

1. List all unique cities where customers are located.
2. Count the number of orders placed in 2017.
3. Find the total sales per product category.
4. Calculate the percentage of orders paid in installments.
5. Count the number of customers from each state.
6. Calculate the number of orders per month in 2018.
7. Find the average number of products per order, grouped by customer city.
8. Calculate the percentage of total revenue contributed by each product category.
9. Identify the correlation between product price and how often a product is purchased.
10. Calculate the total revenue generated by each seller, and rank sellers by revenue.
11. Calculate the moving average of order values for each customer over their order history.
12. Calculate the cumulative sales per month for each year.
13. Calculate the year-over-year growth rate of total sales.
14. Calculate the customer retention rate (percentage of customers who order again within 6 months of their first purchase).
15. Identify the top 3 customers by total spend for each year.

## Prerequisites

## Setup

1. Import the e-commerce dataset (customers, orders, order_items, payments, products, sellers tables) into a MySQL database named `ecommerce`.
2. Update the database connection credentials in the notebook if needed:
   ```python
   db = mysql.connector.connect(
       host="localhost",
       username="root",
       password="12345",
       database="ecommerce"
   )
   ```
3. Open and run `python_sql_ecommerce.ipynb` in Jupyter Notebook / JupyterLab.
